# imx6ull-vehicle-terminal

基于 i.MX6ULL(韦东山 100ask 开发板)的车载座舱终端系统:开源车载终端(QT + 多外设)的移植改造,含自写内核驱动、自写数据采集服务与 ENET 驱动栈深挖。

> QT 应用基于[正点原子开源车载终端项目](https://blog.csdn.net/black_sneak/article/details/131889750)移植改造,本项目负责平台适配、驱动开发与系统集成。

## 系统架构

```
┌─────────────────────────────────────────────┐
│                QT 座舱界面                    │
│   (linuxfb + tslib,温湿度实时显示/按键响应)     │
└──────────────┬──────────────────────────────┘
               │ sysfs / dev 节点 / TCP
┌──────────────┴──────────────────────────────┐
│    veh_term_service(TCP 9000,select 多路复用) │
│    每秒采样 DHT11 + input 按键事件 + JSON 上报  │
└──────┬───────────────────┬───────────────────┘
       │ read /dev/dht11   │ input 事件
┌──────┴─────────┐  ┌──────┴───────────────────┐
│ DHT11 单总线驱动 │  │ AP3216C I2C 驱动(自写)     │
│ (字符设备)      │  │ (i2c_driver+misc+sysfs)  │
└────────────────┘  └──────────────────────────┘
│                 ENET:LAN8720A 百兆 PHY + fec  │
└──────────────────────────────────────────────┘
```

## 目录

| 目录 | 内容 |
|---|---|
| `drivers/ap3216c/` | AP3216C 环境光/接近/红外传感器 I2C 内核驱动(自写) |
| `drivers/dht11/` | DHT11 单总线字符设备驱动 + 用户态测试程序 |
| `app/` | veh_term_service:TCP 数据采集服务(自写 C,select 多路复用) |
| `dts/` | 设备树改动节点与说明 |
| `notes/` | 网络驱动深挖笔记 |
| `qt/` | QT 应用移植说明 |

## 技术要点

- **内核与设备树适配**:4.1 → 4.9 API 适配;DHT11 引脚重映射(正点原子 GPIO1_IO03 未引出 → GPIO4_IO21)
- **自写驱动**:
  - AP3216C:i2c_driver + of_match_table 匹配,misc 挂 class 固定用户态路径,sysfs 属性暴露——替代原项目应用层裸操作 /dev/i2c
  - DHT11:platform_driver + 单总线时序(spin_lock_irqsave 保护采样时序),字符设备接口
- **数据采集服务**:select 统一管理定时采样/按键事件/客户端连接,JSON 行协议,单进程多路 IO
- **ENET 驱动栈深挖**:BD 环形缓冲、NAPI 中断+轮询混合机制、PHY 自协商状态机(详见 notes/网络驱动笔记.md)
